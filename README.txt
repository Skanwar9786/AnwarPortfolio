ANWAR PORTFOLIO — START HERE

1. Extract this folder (if it is a ZIP).
2. Keep the folder structure unchanged:
   AnwarPortfolio_Fresh/
     index.html
     resume.html
     assets/
       profile.jpg
       nature.jpg
3. Double-click index.html to open the portfolio in your browser.
4. Use the Experience button to view All Digi Tech experience.
5. Use View Resume to open resume.html in a new tab.
6. On the resume page, click Print / Save as PDF and choose "Save as PDF" in the printer dialog.
7. To update the profile picture, replace assets/profile.jpg with your image, keeping the same filename.
8. To change the background, replace assets/nature.jpg, keeping the same filename.

This is a local website. It will not have a public internet URL until you publish it using a hosting service.
